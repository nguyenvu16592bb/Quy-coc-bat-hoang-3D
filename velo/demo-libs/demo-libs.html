Elemental Monsters: Merge — Velo Engine + PixiJS + Phaser trên 1 trang

3 engine chạy đồng thời: Velo (game WebGL) + PixiJS (overlay/HUD) + Phaser (menu/loading). Tất cả lib local trong vendor/.

1. Velo Engine — game chính (iframe)

2. PixiJS — overlay HUD (canvas trong suốt)

PixiJS vẽ hiệu ứng chồng lên không phụ thuộc vào Velo. Cách ghép thật vào game: đặt canvas Pixi phủ trên canvas Velo (position:absolute; pointer-events:none) và đồng bộ qua một biến global — ví dụ window.gameBridge = { coins: 0 } mà cả 2 engine cùng đọc/ghi.

3. Phaser — màn menu / loading

Phaser chạy scene riêng (menu, hướng dẫn, chọn ngôn ngữ) trên canvas của nó. Khi player bấm "VÀO GAME" bên dưới, trang ẩn canvas Phaser và hiện iframe Velo. Đây là mô hình phổ biến: Phaser làm khung app, Velo chạy màn gameplay.
